# 현답 Hyundap — 오늘의 지혜를 슬쩍 빌려 보세요

고민을 적으면 고사성어·사자성어와 인물의 관점을 빌려 1–5분짜리 "오늘의 작은 실천"을 만들고, 저녁에 체크인해 기록하는 모바일 우선 웹앱입니다. 추천은 로컬 콘텐츠와 결정적 태그 매칭으로만 동작합니다(AI/API 없음).

## 진입 경로
- `index.html` — 앱 전체(SPA). 첫 방문 시 온보딩 → 홈.
- 설정 > "온보딩 다시 보기"로 온보딩 재생.

## 로고 규칙
- 기본 언어: 한국어. 선택 언어는 `hy.lang.v1`에 저장되어 다음 방문·모든 화면에 적용.
- 온보딩: 한국어 = `assets/logo_ko_orange.png`(현답), English = `assets/logo_en_orange.png`(Hyundap). 같은 왼쪽 상단, 비율 유지(높이 42px / 27px로 시각 크기 맞춤), 하나만 표시.
- 메인 이후 모든 화면(홈 상단, 설정 하단): 언어 무관 `assets/symbol_quote.png` 따옴표 심볼만, 글자 없음.

## 온보딩 영상
- `assets/onboarding_icons.mp4` (5:4, 12s, 60fps, 흰 배경). 두 언어 동일, 언어 전환 시 재시작 없음.
- 반응형: 텍스트 아래 남은 공간을 채우는 영역(`object-fit: contain`)에 배치해 어떤 화면 높이에서도 텍스트와 겹치지 않음. `mix-blend-mode: multiply`로 흰 배경이 앱 배경에 녹아듦. 화면이 낮으면 영상 최소 높이(210/170px)를 확보하고 스크롤.

## 한/영 전환 (KR / ENG)
- 홈·탐색·기록 상단 우측(알림 종 아이콘 오른쪽), 온보딩 상단, 설정 > 언어에 KR/ENG 토글.
- 토글 스타일: 1px #EDEDED 테두리, 선택 = #FF7336 배경 + 흰 글씨, 비선택 = #ABABAB.
- 모든 UI 문구, 주제·키워드, 카드 24개, 인물 8명, 질문·실천 템플릿, 날짜·상태가 영어로 전환됩니다. 영어 입력 고민도 감지됩니다.
- 저장 키 `hy.lang.v1`. 기록은 카드/인물 이름을 현재 언어로 다시 표시하고, 사용자가 쓴 텍스트(고민·답·실천)는 쓴 언어 그대로 유지합니다.

## 인물 관점 화면
- 260px 원형: 위쪽 흰색 + 눈금 호, 아래로 갈수록 진해지는 오렌지 그라데이션, 한글 이름 + 영문 렌즈(예: STOIC THINKING) + 큰 영문 이름(좁은 자간), 하단 빨간 점.
- 이름은 1.05s ease-out(blur→선명)으로 부드럽게 낙하, 글자 간 45ms 간격.
- 인물 카드는 항상 4명(2×2)씩, 흰 배경 + 1px #FE9F5D 테두리, 선택 시 오렌지. "다른 관점 보기 1/2"로 나머지 4명.

## 흐름 / 화면
온보딩 → 홈(고민 입력·칩·오늘의 지혜·오늘의 실천) → 키워드(1/5) → 지혜 카드(2/5, 페이지당 성어 2 + 관점 1) → 인물 관점(3/5, 이름 낙하 애니메이션) → 질문(4/5) → 실천(5/5) → 저장 → 저녁 체크인 → 내 기록 / 상세 / 알림 / 설정.
탭: 홈 · 지혜 탐색 · 내 기록.

# 현답 | 빌린 지혜로 나만의 답 찾기

현답은세대 간 소통이 줄어들며 자연스럽게 단절되고 있는 
이전 세대의 경험과 지혜를 오늘의 삶과 다시 연결하는 서비스입니다. 
옛 지혜와 철학자의 관점을 빌려
일상의 고민을 새로운 시선으로 바라보고,
작은 실천으로 연결하도록 돕는 서비스입니다.

## 프로젝트에서 다룬 질문

좋은 말을 읽는 데서 그치지 않고,
그 지혜를 나의 고민과 오늘의 행동에 연결하려면
어떤 경험이 필요할까요?

## 사용자 흐름

고민 입력 → 키워드 선택 → 지혜 탐색 → 관점 빌리기
→ 오늘의 실천 → 체크인 → 기록

## 주요 설계

- 하나의 답을 바로 제시하기보다 여러 관점 중 사용자가 직접 선택하도록 구성했습니다.
- 선택한 관점의 질문을 통해 자신의 생각을 정리하도록 구성했습니다.
- 작은 실천을 정하고, 이후 체크인과 기록을 통해 돌아볼 수 있도록 했습니다.

## 내가 맡은 역할

- 실제로 맡은 기획·조사·디자인·구현: [세대 간 단절이라는 사회문제의 발견과 문제 정의부터 서비스 콘셉트 기획, 사용자 경험 설계, 정보 구조 및 사용자 플로우 구성, UI 디자인, 프로토타입 제작까지 프로젝트의 전 과정을 주도했습니다.
  ‘Mimic’이라는 디자인 철학을 바탕으로 옛 지혜를 오늘의 고민과 연결하는 서비스 구조를 구체화했습니다.]
- 사용한 도구와 AI의 활용 범위: [Figma를 중심으로 UX/UI와 프로토타입을 제작했으며, 생성형 AI를 활용해 아이디어 탐색, 콘텐츠 구조화, 사자성어·고사성어와 철학자의 관점을 연결하는 초기 콘텐츠 탐색, 이미지 및 비주얼 콘셉트 제작을 진행했습니다.
  AI가 제안한 결과를 그대로 사용하는 것이 아니라 서비스의 방향과 맥락에 맞게 직접 선별하고 수정하여 디자인에 적용했습니다.]

## 문제 정의와 디자인 적용

- 문제: [관련 뉴스와 사례를 조사하며 세대 간 소통의 감소가 단순한 가치관 차이를 넘어, 이전 세대가 삶을 통해 축적해 온 경험과 지혜가 다음 세대로 자연스럽게 전달되기 어려워지는 문제로 이어지고 있다는 점에 주목했습니다. 젊은 세대가 옛 지혜를 고리타분한 이야기로 받아들이는 것이 아니라,
        일상의 고민 속에서 쉽게 접하고 활용할 수 있는 새로운 전달 방식이 필요하다고 보았습니다.]
  <img width="1920" height="1080" alt="Social Issue" src="https://github.com/user-attachments/assets/64a1a306-6bfd-4f8e-88cf-6ef0f98c0c50" />
- 모방의 원리: [아이들이 어른의 말과 행동을 관찰하며 배우듯, 사람은 다른 사람의 경험과 태도를 관찰하고 모방하며 성장합니다. 저는 이 원리를 ‘Mimic’과 연결하여, 먼저 살아본 사람들의 지혜와 사고방식을 그대로 따라 하는 것이 아니라 오늘의 상황에 맞게 다시 해석하고 나의 삶에 적용하는 과정으로 확장했습니다.]
- 디자인 적용: [사용자가 현재의 고민이나 키워드를 입력하면 관련된 사자성어와 고사성어, 삶의 지혜를 탐색하고 그와 연결된 철학자와 사상가의 관점을 빌려 자신의 고민을 다시 바라보도록 설계했습니다. 지혜의 의미를 읽는 것에서 끝나지 않고, 오늘 직접 해볼 수 있는 작은 행동을 정하고 실천과 기록으로 이어지도록 구성했습니다.]

## 설계 과정과 판단

- 여러 관점을 고르게 한 이유: [하나의 고민에도 정답은 하나가 아니라고 생각했습니다. 같은 상황이라도 시대와 문화, 사람이 가진 가치관에 따라 문제를 바라보는 방식은 달라질 수 있습니다.
  따라서 서비스가 특정한 답을 내려주기보다, 사자성어·고사성어와 여러 철학자·사상가의 서로 다른 관점을 제시하고 사용자가 지금 자신의 상황에 가장 와닿는 관점을 직접 선택하도록 설계했습니다. 이를 통해 ‘지혜를 알려주는 서비스’가 아니라 ‘다른 사람의 사고방식을 잠시 빌려 스스로 답을 찾아가는 서비스’를 만들고자 했습니다.]
- 작은 실천과 기록을 연결한 이유: [좋은 말을 읽고 이해하는 것만으로는 삶의 변화로 이어지기 어렵다고 생각했습니다. 결국 행동하지 않으면 아무것도 달라지지 않기 때문에, 선택한 지혜를 오늘 바로 해볼 수 있는 작고 구체적인 실천으로 연결했습니다.
  이후 실천 여부와 느낀 점을 기록하게 함으로써 옛사람의 말이 단순히 고리타분한 조언으로 끝나는 것이 아니라, 직접 경험을 통해 나에게 의미 있는 ‘지혜’이자 지금의 문제에 대한 ‘현답’으로 남도록 하고자 했습니다.]
