# 현답 Hyundap — 오늘의 지혜를 슬쩍 빌려 보세요

고민을 적으면 고사성어·사자성어와 인물의 관점을 빌려 1–5분짜리 "오늘의 작은 실천"을 만들고, 저녁에 체크인해 기록하는 모바일 우선 웹앱입니다. 추천은 로컬 콘텐츠와 결정적 태그 매칭으로만 동작합니다(AI/API 없음).

## 진입 경로
- `index.html` — 앱 전체(SPA). 첫 방문 시 온보딩 → 홈.
- 설정 > "온보딩 다시 보기"로 온보딩 재생.

## 로고 규칙
- 기본 언어: 한국어. 선택 언어는 `hy.lang.v1`에 저장되어 다음 방문·모든 화면에 적용.
- 온보딩: 한국어 = `assets/logo_ko_orange.png`(현답), English = `assets/logo_en_orange.png`(Hyundap). 같은 왼쪽 상단, 비율 유지(높이 42px / 27px로 시각 크기 맞춤), 하나만 표시.
- 메인 이후 모든 화면(홈 상단, 설정 하단): 언어 무관 `assets/symbol_quote.png` 따옴표 심볼만, 글자 없음.

## 온보딩 영상
- `assets/onboarding_icons.mp4` (5:4, 12s, 60fps, 흰 배경). 두 언어 동일, 언어 전환 시 재시작 없음.
- 반응형: 텍스트 아래 남은 공간을 채우는 영역(`object-fit: contain`)에 배치해 어떤 화면 높이에서도 텍스트와 겹치지 않음. `mix-blend-mode: multiply`로 흰 배경이 앱 배경에 녹아듦. 화면이 낮으면 영상 최소 높이(210/170px)를 확보하고 스크롤.

## 한/영 전환 (KR / ENG)
- 홈·탐색·기록 상단 우측(알림 종 아이콘 오른쪽), 온보딩 상단, 설정 > 언어에 KR/ENG 토글.
- 토글 스타일: 1px #EDEDED 테두리, 선택 = #FF7336 배경 + 흰 글씨, 비선택 = #ABABAB.
- 모든 UI 문구, 주제·키워드, 카드 24개, 인물 8명, 질문·실천 템플릿, 날짜·상태가 영어로 전환됩니다. 영어 입력 고민도 감지됩니다.
- 저장 키 `hy.lang.v1`. 기록은 카드/인물 이름을 현재 언어로 다시 표시하고, 사용자가 쓴 텍스트(고민·답·실천)는 쓴 언어 그대로 유지합니다.

## 인물 관점 화면
- 260px 원형: 위쪽 흰색 + 눈금 호, 아래로 갈수록 진해지는 오렌지 그라데이션, 한글 이름 + 영문 렌즈(예: STOIC THINKING) + 큰 영문 이름(좁은 자간), 하단 빨간 점.
- 이름은 1.05s ease-out(blur→선명)으로 부드럽게 낙하, 글자 간 45ms 간격.
- 인물 카드는 항상 4명(2×2)씩, 흰 배경 + 1px #FE9F5D 테두리, 선택 시 오렌지. "다른 관점 보기 1/2"로 나머지 4명.

## 흐름 / 화면
온보딩 → 홈(고민 입력·칩·오늘의 지혜·오늘의 실천) → 키워드(1/5) → 지혜 카드(2/5, 페이지당 성어 2 + 관점 1) → 인물 관점(3/5, 이름 낙하 애니메이션) → 질문(4/5) → 실천(5/5) → 저장 → 저녁 체크인 → 내 기록 / 상세 / 알림 / 설정.
탭: 홈 · 지혜 탐색 · 내 기록.

## 파일
| 파일 | 내용 |
|---|---|
| `index.html` | 셸, 폰트(Pretendard), React 18 + Babel standalone 로드 |
| `hy-styles.css` | 디자인 토큰과 모든 스타일 (클라이언트 제공) |
| `hy-data.jsx` | 주제·키워드·시나리오 8개, 카드 24개(성어 12 + 관점 12), 인물 8명 |
| `hy-i18n.jsx` | 한/영 번역 사전, `tr()`·`cardT()`·`personaT()` 헬퍼, KR/ENG 토글 |
| `hy-engine.jsx` | 감지, 카드 점수/2+1 페이징, 인물 순위, 질문/실천 템플릿, 날짜 헬퍼, localStorage |
| `hy-ui.jsx` | 아이콘, 로고, 헤더, 버튼, 탭바, 지혜 카드, 온보딩 비디오, 인물 오브 |
| `hy-main.jsx` | 온보딩, 홈, 탐색, 기록, 상세, 알림, 설정 |
| `hy-flow.jsx` | 키워드, 지혜, 인물, 질문, 실천, 체크인 |
| `hy-app.jsx` | 내비게이션 스택, 영속화, 저장/체크인/다시 실천 |
| `assets/` | `onboarding_icons.mp4`, `logo_ko_orange.png`, `logo_en_orange.png`, `symbol_quote.png`, `ref/`(레퍼런스) |
